Hi, I'm Ian. Most weeks in Claude Code Latest I walk through plugin updates. This week I want to talk about something different. I've been using Claude Duet, Anthropic's new always-on personal agent app. Here's what it's actually doing for me.

# First impression

The first thing I liked is simple. I run a lot of scheduled tasks in Cowork. Before, I only found out one had failed when I logged in and went looking. Now Duet watches those tasks and tells me how they went. If something breaks, I hear about it. If everything worked, it stays quiet. That alone changed how I think about automation.

# Example one: the podcast schedule

I run a daily AI news podcast called AI At The Edge. It's built and published by a GitHub workflow every night. A few weeks in, the episodes kept showing up late. Not a few minutes late. Six or seven hours late.

So I asked Duet to figure it out. It sent three agents to research the problem on their own. They came back and agreed on the cause. GitHub was starting my scheduled runs hours after the time I set. The fix was to move the run to twelve thirteen in the morning, New York time. The idea is simple. Even if a run starts late, the episode is still ready before I wake up.

# Example two: longer episodes from one text

The episodes used to run about five minutes. One night I sent Duet a single text asking if we could make them about ten. By morning it had changed the settings, updated the show notes, and pushed the change. One message, and it carried the work all the way through.

# Example three: one channel per subject

I keep one channel in Duet for each part of my life. One for the podcast. One for growing on LinkedIn. One for church worship planning. Each channel has its own routines. And here's the part I like most. Those routines only post when something actually needs me. No daily noise. Just a heads up when I have something to decide.

# Example four: research about Duet itself

Before I wrote this, I asked Duet to do deep research on how other people are using it. That research shaped what I'm telling you now. It's a little funny to have an agent research itself. But it gave me good ideas, and it helped me see what's still rough.

# Example five: church admin

I also help with admin at my church. Every week Duet prepares the drafts I need. I review them, make my edits, and send them myself. It does the busy work. I keep the final say.

# Honest take

To be fair, Duet is new. It's waitlisted, and some reviewers say it can feel slow. I've seen that too. But for me, the trade is worth it. It doesn't replace my judgment. It takes the follow-up off my plate.
