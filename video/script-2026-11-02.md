# Hook

Hi, I'm Ian. Most weeks in Claude Code Latest I walk through plugin updates. This week is different. I want to talk about Claude Duet, Anthropic's new always-on agent app.

# The pitch

Anthropic pitches it as an agent that keeps working when you stop. It checks your apps, sends you a morning brief, and pings you only when something needs you. Most reviews I read stopped at the morning brief. Some testers even said they forgot to use it. I went the other way. I gave it the night shift.

# It watches my automations

Here's what I mean. I run a lot of scheduled jobs in Cowork. Before, I only found out one had failed when I logged in and went looking. Now Duet watches those jobs and tells me how each one went. If something breaks, I hear about it. If everything worked, it stays quiet. It watches my automations, not just my inbox.

# It fixed my podcast while I slept

I run a daily AI news podcast called AI At The Edge. A GitHub workflow builds and publishes it every night. A few weeks in, the episodes kept landing about six hours late. Some days I had to start them by hand.

So I asked Duet to dig in. It sent agents to research the problem on their own. They came back and agreed on the cause. GitHub was starting my scheduled run hours after the time I set. So we moved the run to twelve thirteen in the morning. And it worked. The next episode published on its own at six nineteen in the morning. No button from me.

# One text, done by morning

The episodes used to run about five minutes. One night I sent Duet a single text asking for about ten. By morning, the change was in. One message, and it carried the work through.

# It runs this newsletter

Here's the part that still surprises me. A weekly routine in Duet reads the Claude Code changelog, writes the cards for this newsletter, and builds the cover. I review it and say go. It even built the workflow that turned this section into the video you're watching.

# It stays quiet

I keep one channel in Duet for each subject. One for the podcast. One for growing on LinkedIn. One for church worship planning. The routines in each channel only post when something needs me. It drafts my email replies and my weekly church drafts, and I send them myself. It does the busy work. I keep the final say.

# Honest take

Now the honest part. It can be slow. And it checks in every few hours, not every minute. For live chat, that would bug me. For night shift work, it's fine.
