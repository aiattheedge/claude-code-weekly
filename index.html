Security NEW · v2.1.304

Audit your agents against Anthropic's own security guide

Shipping an agent and not sure the settings are safe?

Time 2 minLevel beginnerFor agent builders
What
A skill is a saved set of instructions that Claude follows. The built-in /claude-api skill has a new check. It compares your Managed Agents settings with Anthropic's published security guide. It does not change anything.
Why
You get a safe review before you ship.
Needs
Version 2.1.304 or later.
Run inside a Claude Code session, in a project that has agent settings:
/claude-api managed-agents-secure
Did it work? Claude lists where your settings differ from the guide. Your files stay the same.
Skills CHANGED · v2.1.304

Test a skill the second you save it

Tired of restarting just to test a new skill?

Time 5 minLevel beginnerFor solo devs
What
You can add a new skill folder while a session is open. /reload-skills makes Claude see it. Since v2.1.304 it sends only new or changed skills. That keeps your chat small.
Why
Write a skill, reload, and try it. No restart.
Needs
The docs name no version for the command. The newer behavior is in 2.1.304.
.claude/skills/explain-code/SKILL.md (the usual place for a project skill; text adapted from the docs example)
---
name: explain-code
description: Explain what a piece of code does in plain words
disable-model-invocation: true
---

Explain the code I point to. Use short sentences.
Then, in your open session:
/reload-skills
Did it work? Type / and look for explain-code in the menu.
Hooks EASY TO MISS · v2.1.295

Stop a tool call when your hook breaks

What happens if your safety check crashes?

Time 10 minLevel intermediateFor team leads
What
A hook is a small program that runs at a set moment, like before a command. The onFailure setting tells Claude Code what to do if your hook fails. The docs list two values: block and continue.
Why
A broken safety check will not quietly let risky commands through.
Needs
Version 2.1.295 or later.
.claude/settings.json (swap in your own script path)
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "node",
            "args": ["\${CLAUDE_PROJECT_DIR}/.claude/hooks/check-command.js"],
            "onFailure": "block"
          }
        ]
      }
    ]
  }
}
Did it work? Rename the script for a minute and ask Claude to run a shell command. I expect the call to be blocked. Rename it back after.
Packaging EASY TO MISS

One command installs a whole toolkit

Onboarding a new teammate takes six installs?

Time 15 minLevel intermediateFor team leads, plugin authors
What
A plugin can list other plugins it needs. These are called dependencies. A plugin with only a name and a list is valid, so you can build a "starter pack" for your team.
Why
A new teammate runs one command, not six.
Needs
The docs page names no minimum version.
.claude-plugin/plugin.json (names are the docs' examples; use plugins from your store)
{
  "name": "backend-standard",
  "version": "1.0.0",
  "description": "Standard plugin set for backend engineers",
  "dependencies": [
    "secrets-vault",
    "deploy-kit",
    { "name": "db-migrate", "version": "^3.0" },
    "oncall-runbook"
  ]
}
Install it:
claude plugin install backend-standard@your-marketplace
Did it work? Run claude plugin list in your terminal and look for the other plugins.
Testing EASY TO MISS · v2.1.269

Give your plugin a report card

How do you know a plugin change did not make things worse?

Time 20 minLevel advancedFor plugin authors
What
claude plugin eval runs sample requests against your plugin and scores the answers. It also runs them without your plugin, so you see what the plugin adds. Each case runs three times by default.
Why
You learn if a change made things worse before your users do.
Needs
Version 2.1.269 or later. It uses your model credits, so start small.
In your plugin folder: make a blank test case, then run the suite
claude plugin eval init --bare first-case
claude plugin eval .
To fail a CI job when a score is low (from the docs):
claude plugin eval . --trust-plugin --json results.json --threshold 0.8
Did it work? You get a table with a score for each case, plus a report.html file.

How to install a plugin

Official store plugins use this form, shown in Anthropic's docs:

/plugin install commit-commands@claude-plugins-official

To add another store first, run /plugin marketplace add <owner>/<repo>. Then use /plugin install <plugin>@<marketplace-name>.

Stay safe

Plugins can run code on your machine. Read what a plugin adds before you install it.
