Plugins FIXED · v2.1.311 · OCT 26

Load a whole folder of plugins at once

Got three plugins in one folder and tired of typing three flags?

Time 5 minLevel beginnerFor plugin authors
What
Point --plugin-dir at the parent folder. Each child folder with a .claude-plugin/plugin.json loads as its own plugin. Before 2.1.311, an empty .mcp.json at the top of that folder made it load as one plugin. That is fixed. Also fixed on Linux: sandboxed Bash failed with bwrap: Can't create file when a --plugin-dir folder was also an added directory.
Why
Test several plugins together, with no install step.
Needs
Version 2.1.311 for the fix. Loading a parent folder needs 2.1.265 or later (docs).
In your shell (folder names are examples):
claude --plugin-dir ./plugins
Did it work? Run /plugin and look for each plugin by its own name.
Plugins NEW · v2.1.310 · OCT 23

Let a plugin watch a log for you

What if Claude could react to an error log without you asking?

Time 10 minLevel intermediateFor plugin authors
What
A plugin monitor is a shell command that runs in the background all session. What it prints reaches Claude as notifications. In 2.1.310, plugin monitors and the Monitor tool work on Bedrock, Vertex and Foundry, and when telemetry or nonessential traffic is off.
Why
Claude can react to a log or a status change without being asked to watch it.
Needs
Version 2.1.310 for those providers. Interactive sessions only, not -p. The command runs with your full user permissions, outside the sandbox.
monitors/monitors.json inside your plugin (the docs' example):
[
  {
    "name": "error-log",
    "command": "tail -F ./logs/error.log",
    "description": "Application error log"
  }
]
Did it work? Run /reload-plugins, then add a line to ./logs/error.log. Claude should be told about it.
Plugins CHANGED · v2.1.304 · OCT 19

Know your plugin's hook limits

How many hooks can one plugin register?

Time 10 minLevel intermediateFor plugin authors, admins
What
A skill is a saved set of instructions Claude follows, and a skill can carry hooks. Since 2.1.304, the skills of one source (a repo, your own folder, or a plugin) can register at most 1,024 hooks and 16,384 matcher characters per session. Also new: under a policy that allows hooks from plugins only, a skill used in the main conversation whose hooks are kept out no longer gets its allowed-tools.
Why
No surprise when a big plugin hits a limit, and no tool access left behind when its hooks are blocked.
Needs
Version 2.1.304 or later.
Check your plugin's files before you load them. In your plugin folder:
claude plugin validate .
Did it work? It reports syntax and schema problems. It does not say it checks the hook limits, so count your own hooks.
Headless FIXED · v2.1.304 · OCT 19

Stop runaway plugin runs

What if a plugin keeps a scripted run going after it should stop?

Time 5 minLevel beginnerFor CI users, scripters
What
A plugin could keep a headless run going past --max-turns, a Stop hook, or ended input by spawning subagents or re-running a finished one. That is fixed in 2.1.304.
Why
Your CI job ends when you told it to end.
Needs
Version 2.1.304 or later. This command is my example, not from the changelog.
In your shell:
claude -p "summarize this repo" --max-turns 3
Did it work? The run stops after at most three turns, even with plugins loaded.

  • 2.1.305: plugins that Claude Desktop mounts by path no longer keep their allowed-tools when your organization's managed settings set allowManagedPermissionRulesOnly.
  • 2.1.304: a claude.ai Directory plugin's skills now run as commands when picked from the "/" menu in Cowork cloud sessions.
  • 2.1.304: a transcript line now says when a plugin that runs first skips one of your mod's hooks, naming the event and the plugin.
  • 2.1.304: claude plugin validate no longer prints notes that predicted where a mod's hooks would run.

How to install a plugin

Official store plugins use this form, shown in Anthropic's docs:

/plugin install commit-commands@claude-plugins-official

To add another store first, run /plugin marketplace add <owner>/<repo>. Then use /plugin install <plugin>@<marketplace-name>.

Stay safe

Plugins run code on your machine. Plugin monitors run with your full user permissions, outside the sandbox. Read what a plugin does before you install it.
